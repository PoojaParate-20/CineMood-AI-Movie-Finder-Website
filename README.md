# CineMood-AI-Movie-Finder-Website
CineMood — An AI-inspired, vibe-driven movie discovery app built with React, Tailwind CSS, and the TMDB API. Find films by mood, intensity, and aesthetic instead of traditional genres.

# 🎬 CineMood — AI-Powered Movie Finder by Vibe & Emotion

**CineMood** redefines movie discovery by shifting the focus from standard genres to emotional vibes, settings, and intensity levels. Built with full-stack React and powered by the TMDB API, CineMood helps users discover what to watch based on how they want to feel.

---

## ✨ Features

- 🎭 **Vibe & Mood Selector:** Filter movies by curated aesthetic tags (*"Cozy Rainy Sunday"*, *"Mind-bending Space Mystery"*, *"Nostalgic 90s Thriller"*).
- 🎚️ **Intensity Controls:** Adjust dark, upbeat, and suspenseful sliders to fine-tune recommendations.
- 🎴 **Interactive Card Deck:** Swipe right to save to your personal Watchlist or swipe left to skip.
- 🍿 **Rich Media Integration:** Live fetching of poster artwork, IMDb ratings, overview specs, and official YouTube trailers via TMDB API.
- 📺 **"Where to Watch":** Real-time streaming provider availability (Netflix, Prime Video, Disney+, etc.).
- 💾 **Local Storage Persistence:** Saved Watchlist items persist across browser sessions.

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, Framer Motion
- **Icons:** Lucide React
- **API:** The Movie Database (TMDB) API
- **Deployment & Dev:** Built with Bolt.new / Vite
